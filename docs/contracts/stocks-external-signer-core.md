# Stocks external signer core — inactive local slice

This module is an unconnected protocol boundary for the existing `ARCO_STOCKS_SIGNER_V1` client. It does not start a listener, implement `GET /v1/capabilities`, claim `DURABLE_SERIALIZED` or `IMMUTABLE_IDEMPOTENT`, access a key, reserve a real nonce, or broadcast a transaction. It is not a public signer service and cannot be configured as `signerUrl`.

`server/src/stocks-runtime/signer-call.ts` now supplies one canonical allowlist to the client and the future service. Only `mintForOperation`, `refundForOperation`, `settleRedemption`, and `returnEscrowForOperation` are accepted, with their matching `mint:`, `refund:`, `redeem:`, and `return:` operation IDs. The call must match the reviewed manifest's chain, deployment, signer, target, exact calldata and zero value. `parseStocksSignerPut` additionally requires the exact v1 request fields, deployment digest, path operation ID and call digest before touching a journal.

`createStocksSignerCore` reserves the immutable original operation **and its decimal `originalNonce`** through an injected journal before invoking an injected one-shot transport. A missing or malformed nonce is rejected before that call. A repeated PUT for the same ID returns its recorded hash, or an unknown result when no hash is proven; it never invokes the transport again. A changed payload under that ID is rejected. Lookup reads only the original ID and passes its persisted nonce and call to the transport's read-only original-transaction lookup. An absent result never authorizes another send. Store and transport exceptions are reduced to fixed errors without raw provider or database details.

The injected ports have requirements that the core alone cannot prove. The separate [inactive PostgreSQL journal](stocks-signer-journal-postgres.md) now uses one database transaction to commit the original operation and nonce before transmission, serializes allocation with a physical account lock, preserves immutable records across restarts, and blocks later nonces while an earlier outcome is unresolved. `recordHash` is compare-and-set and never replaces a different hash. Its disposable PostgreSQL tests verify those database behaviors; the core's tests use fake ports. A production transport must sign only the exact reserved call at `originalNonce` once and find only a transaction with the same signer, nonce, target, calldata and zero value after ambiguity; an unknown lookup cannot trigger a new send.

Before exposing an HTTPS endpoint or a capabilities response, implement and independently test the signing and original-transaction lookup transport against a local EVM, including process crashes before and after send. Then validate restricted database custody, verified nonce seeding, selected external signing custody, and public GIWA deployment evidence separately. The existing local Hardhat signer remains test-only.
